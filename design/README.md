# design/

Approved screen designs, one folder per screen: `NN-<slug>/png/<board>-light.png` and `<board>-dark.png`.

Source canvases stay in claude.ai (links in `docs/screen_status.md`). Every change to a screen arrives in a `design-change` pull request with the updated PNGs and a new design version + change note in `docs/screen_status.md`.
